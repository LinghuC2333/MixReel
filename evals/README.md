# 创作行为验证

这些测试检查助手是否改变了实际选择。自动测试通过并不能证明故事有吸引力。

`cases.json` 包含独立的合成情境，不涉及客户故事。将一条情境交给执行者，仅提供该条 request 和 materials。使用 skill 的实验组同时读取入口及必要参考文件，无 skill 的对照组不读取。评分者再读取 `rubric.json`，不要提前把预期答案交给执行者。

让两个组使用相同模型、权限和原始资料。保存完整回答、实际读取的文件、时间和工具调用。所有情境限定为本地文字作业，不允许付费生成或向外发送消息。是否使用独立助手由宿主权限和用户授权决定，本测试包不自行创建任务。

评分针对可观察行为，检查是否守住情绪类型、是否给出可视证据、是否在新音乐下重新安排镜头，以及是否在结果未知时拒绝重复提交。记录合理但不同的答案，不用关键词命中率代替判断。

当对照组与实验组都正确时，不能声称该规则带来了提升。保留差异和失败证据，必要时补充更有区分度的情境。多人评分出现分歧时，记录分歧，不把平均分包装成审美定论。

当前版本已准备测试题和评分标准，尚未进行独立模型对照测试。下一次真实视频提案可以检验创作部分，付费生成效果需要另外记录。
