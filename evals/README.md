# 用真实任务验证

选择一个用户确实要完成的任务，准备可观看的参考视频、角色与故事资料、目标音乐，以及受众、用途和改编范围。使用获准访问的素材，将原文件和执行记录留在私人项目目录。

让助手使用本 skill，先完成参考分析、音乐片段选择和可逐镜审阅的提案。本轮验证到提案为止，生图与视频另按用户授权执行。保存使用的模型、skill 版本、实际读取材料和完整提案。

由用户或其他审阅者按下面的维度查看画面描述，并指出具体镜头和理由。

| 维度 | 审阅内容 |
|---|---|
| 参考理解 | 是否解释了观众体验怎样随画面变化，并有时间位置作为依据 |
| 用户意图 | 是否回应了本次受众、用途和用户想保留的部分 |
| 故事改编 | 原著出处与改动是否清楚，不同方向是否值得比较 |
| 画面表达 | 不熟悉作品的人能否从逐镜画面理解发生的事情 |
| 音乐安排 | 画面时长与音乐是否相容，动作和反应是否有时间被看清 |
| 整体感受 | 连起来是否产生用户想要的观看体验，哪些地方仍有差距 |

不预设故事选择或镜头答案。记录接受、修改和否定的理由，保留审阅分歧。需要比较 skill 的作用时，可用同一模型和相同材料另做一次不用 skill 的提案，再由人比较，不能凭一次满意结果声称普遍有效。

本地程序测试仅验证工具行为。真实提案和生成效果的评判应单独记录。

## 独立 skill 验证

逐项使用 [行为用例](CASES.md)，覆盖统筹及六个专用 skill，脚本包含跨产品、真实私有材料和换音乐三种情况。安装验证需从独立目标目录运行。程序测试、作者按规则试跑、独立审阅和付费生成效果分别报告，不相互代替。

验证记录应包含输入、实际读取的 skill 版本、产物、观察到的问题、修正、仍未检查的部分。不得只凭符合预期的规则文字或自评分宣称效果通过。当前用例没有自动运行另一个模型，也不授予付费测试权限。

See [trial results](RESULTS.md) for what was actually exercised and the remaining quality checks.
