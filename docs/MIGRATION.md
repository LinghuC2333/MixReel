# 旧版迁移

旧版只作为理解需求的材料，安装此版本不会删除或修改旧文件。

| 旧内容 | 新位置或处理 |
|---|---|
| 主入口中的项目复盘、角色和价格 | 从公开包移出，保留在私人项目记录 |
| 故事与节拍说明 | 拆为 analysis、story 和 storyboard |
| 图片生成流程 | 按选构图参考、GPT 简易稿、Ideogram、GPT 修正的分工执行 |
| Seedance 2 与 H3 视频提示词写法 | 分别迁入模型专用参考文件，按需读取 |
| H3 或网关字段、并发数和价格 | 项目 providers 目录，使用前核实 |
| 固定四道确认 | 根据已授权范围检查具体产物，不重复询问 |
| 每次从零运行批处理 | 执行前查 journal，保留未知结果与费用 |
| 原报价、提交、剪辑脚本 | 不直接迁入，避免把服务假设和隐含默认值带入通用包 |
| 自动切镜和帧差 | 新写本地诊断工具，仅输出候选，保留音画检查 |
| 题材、画风和单次失败判例 | 移出通用说明，改用创作步骤与真实任务审阅 |

需要继续使用原供应商脚本时，先检查它是否符合 providers 中的契约，尤其是报价不会生成、参考图没有被静默丢弃、超时不会重复提交，以及失败调用是否记账。通过后可作为宿主工具使用，不需要把供应商写进入口。

迁移项目记录时先标记哪些素材被用户接受，哪些已经否定。不能用旧状态文件中的完成标记覆盖用户后来的否定意见。

## 七个 skill 的套件版本

原有 `skills/mixreel` 保留为统筹入口和共用资源位置。具体规则迁入 analyze、script、keyframes、video-plan、produce、review 六个同级 skill。原参考文件位置保留跳转说明，原工具路径未变。使用新的本地安装器安装全套，再单独调用所需入口。

脚本或参考分析不再需要提前填写完整生产计划。已有版本 1 和版本 2 的计划及任务记录继续保留；只有进入制作阶段时才补齐实际生成分组和素材。更新不会自动改动私人配置、既有项目或付费任务。
