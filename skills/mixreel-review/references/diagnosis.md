# Review a result and choose the next change

Compare the result with the approved shot, selected references and actual submitted inputs. Describe the visible difference and the evidence for its cause.

Locate the stage where that difference first appeared. Propose a change to that stage's input or execution, explain which later artifacts it affects, and retain accepted work elsewhere.

For regeneration, revise the original inputs to the stage where the problem arose. Do not feed the same model its previous output as the base for its next revision. To continue repairing an existing result, hand it to another stage or model and keep the repair local under [Images, local editing](../../mixreel-keyframes/references/images.md).

When an accepted clip has a defect confined to one shot, regenerate only that shot. Where the endpoint supports frame conditioning, open the new request on the clip's own frame at that shot's start and ask for the minimum duration. Replace only the picture for that interval in the edit and keep the original clip's sound, so score, dialogue timing and the cut grid continue. Check that the replacement matches the neighbouring shots.

Review the changed result against the same target. If it does not improve, revisit the explanation before another paid attempt. Record findings and costs in the private project; a project-specific result does not establish a general rule about a genre, style or model.
