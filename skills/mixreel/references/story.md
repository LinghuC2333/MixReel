# Develop a script from the viewer's experience

## 1. Read the reference over time

Use the observations in [analysis](analysis.md). Follow what the viewer experiences from moment to moment, including anticipation, withheld information, reveals and the feeling left by the ending. Relate those experiences to framing, camera movement, occlusion and editing. Deliver a time-labelled account of how the video works, with uncertain observations marked.

## 2. Establish the user's intent

Read the brief for audience, purpose and what the user wants to carry over from the reference. Resolve missing choices that would change the proposal. Record the intended audience experience alongside the selected music excerpt and adaptation allowance.

## 3. Find moments in the source story

Read relevant passages in context and develop a few genuinely different directions that could create the intended experience. For each, record its source locator, what happens on screen and how much is retained, compressed or newly proposed. Keep proposed changes distinguishable from source events.

## 4. Compare visible scripts

Write each direction as sequential shot descriptions using [storyboard](storyboard.md), including one principal camera setup per shot, observable actions and reactions, clear viewpoint, standalone sentences for important props, and synchronous sound only. Fit the sequence to the target music. Deliver the visual scripts with source notes and timing, so the user can compare what they would actually watch.

## 5. Watch the script before handing it over

Mentally play each sequence as a viewer unfamiliar with the story, without reading the explanatory notes. Compare the experience with the reference and the user's intent. Revise unclear moments and describe the trade-offs between directions. Submit the scripts for shot-by-shot review, with a recommendation grounded in the visible sequence.
