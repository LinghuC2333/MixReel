# Project brief

## Request and scope

Record the requested deliverable, intended audience, emotional effect, duration/aspect constraints and what the user has already authorized. State the current stop point.

## Sources

Link reference video, target music/excerpt, story passages, character consistency references and visual treatment. For each user-provided character consistency reference, record what it covers, such as face, clothing, angles or expressions. Record provenance, immutable local paths or hashes, and any missing evidence. Keep credentials and signed URLs out.

## Advertiser or creative requirements

For marketing tasks, link the brand layer files this film relies on and their versions, then record what is specific to this film, such as the selected message, the story or setting, the desire and familiar point the idea starts from, campaign objective, required copy, desired viewer action and any testing hypothesis. Product facts and claim limits stay in `brand/brand-context.md`; do not copy them here. Skip irrelevant fields for non-marketing work. Keep private product information outside the public package.

## Reference borrowing

Record each relevant dimension, source time/evidence, keep/adapt/exclude/pending, target treatment, reason and decision authority. Choose one or more dimensions according to the request. Record dependencies between music/lyrics/sound and the creative idea; rebuild edit timing when the track changes. Unselected dimensions do not silently control appearance or story.

## Creative decisions

Record style source, story candidate, source-grounded adaptation, timeline approach, identity anchors, chosen provider/account and reasons for choices. Record the user-confirmed prompt roles of each input-image type (composition, style, identity, wardrobe) and the source of each character's selected wardrobe reference. Record the generation grouping and split reasons, necessary new keyframes versus reused assets, intended roles of video/audio references, and per-request duration and cost estimates. Record uncertainty when it affects the result.

## Reviews and spending authority

For each review, record the artifact version/hash, reviewer, decision, evidence pointer and covered scope. Record budget and currency, per-job cap, retry limit and any authorized experiments. Separate delegated agent decisions from user approval.

## Current work

Link stage artifacts, plan, journal, provider profiles and review findings when they exist. Script-only work need not fabricate production fields. Record accepted/rejected asset versions, outstanding defects and the next useful action. New instructions update this section before dependent work resumes.
