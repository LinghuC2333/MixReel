# Project brief

## Request and scope

Record the requested deliverable, intended audience, emotional effect, duration/aspect constraints and what the user has already authorized. State the current stop point.

## Sources

Link reference video, target music/excerpt, story passages, character references and visual treatment. Record provenance, immutable local paths or hashes, and any missing evidence. Keep credentials and signed URLs out.

## Creative decisions

Record style source, story candidate, source-grounded adaptation, timeline approach, identity anchors, chosen provider/account and reasons for choices. Record uncertainty when it affects the result.

## Reviews and spending authority

For each review, record the artifact version/hash, reviewer, decision, evidence pointer and covered scope. Record budget and currency, per-job cap, retry limit and any authorized experiments. Separate delegated agent decisions from user approval.

## Current work

Link plan, journal, provider profiles and review findings. Record accepted/rejected asset versions, outstanding defects and the next useful action. New instructions update this section before dependent work resumes.
