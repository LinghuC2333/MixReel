# Diagnose before another generation

Identify the failed acceptance criterion and compare the relevant evidence. Repair the earliest cause still affecting the result.

| Symptom | Evidence to inspect | First repair |
|---|---|---|
| Beautiful frames, wrong feeling | Reference's emotional progression and candidate source passage | Revisit scene selection before rendering more |
| Story requires an explanation | Visual plan without lore notes | Make the dependency visible or remove it |
| All shots feel alike | Shot functions, scale, viewpoint and gaze | Change coverage where it adds information |
| Characters return to the opening pose | Opening/final instructions and motion path | Remove contradictory endpoints |
| Source photograph changes the style | Ordered roles and actual images passed | Simplify composition input or change rendering route |
| Portrait pose copied | Identity/wardrobe reference framing | Crop identity or separate wardrobe repair |
| Wrong person edited | Mask and target binding | Verify region and mask semantics |
| Style drifts after local repair | Approved style reference and before/after images | Repair the affected frame against the same lock |
| Video becomes realistic or soft | Supported conditioning mode, actual request, source detail and export | Fix discarded style inputs or encoding before increasing resolution |
| Ending deforms | Final state and available anchor support | Simplify the ending or add an appropriate anchor |
| Action misses the music | Actual observed event time vs target event | Recut within handles, then consider retiming or regeneration |
| Costs cannot be explained | Journal, task IDs, provider bill and currency | Reconcile jobs including failures and trials |

A repeated failure with no changed diagnosis is a reason to stop the retry loop. Present the defect, what has been tried and the smallest next test. Do not write a permanent global ban on a model, word or scene type from a single failure.
