# Block the space before images

Use a simple spatial previsualization when staging can fail in ways a text table hides, such as several characters and a crowd, a charge or fight, a point-of-view shot and its reverse, or a prop that must stay in one place. It is optional. Skip it when the staging is simple or an existing reference frame already proves it.

## Build the blocking scene

Use any available 3D tool, from a scripted Blender scene to a game engine or a web viewer. Real scale matters more than detail.

- Represent each named character with a proxy in its own flat colour and keep that colour legend fixed for the project. Plot-critical props and architecture get real positions, such as a throne, a pedestal, a doorway or a staircase.
- Give every approved shot a camera with start and end positions, targets and vertical field of view in the delivery aspect ratio. Animate positions along the script's timeline so the start and end of each shot come from one continuous scene.
- Store positions, facings, gaze targets, weapon or prop directions and camera data in a machine-readable file next to the scene.

Proxies do not prove faces, gaze nuance, hand contact or performance. Record those as not checked.

## Review outputs

Show a top-down plan and the few shots most at risk before building the rest. Extend to every shot after the user accepts the direction.

- The plan is drawn straight down, with names that do not overlap, movement arrows and each camera's position and facing.
- Each shot gets a start and an end render. Check that the subject is not hidden behind foreground figures, that screen direction and eyelines hold across cuts, what lies behind each subject, where every plot prop is, and whether each action fits its time.
- Fix problems inside the scene, for example by moving a camera or opening a gap in a formation, then render again.

## Use the results downstream

- A shot render can be the composition source for a keyframe, in place of a searched or reference-video frame.
- A storyboard sheet lays the generated shots out in playback order with only a panel number on each, in the delivery aspect ratio where possible. Keep captions, UI and production notes out of any sheet given to a model.
- When the video endpoint accepts it, the storyboard sheet can be the first ordered reference image. The prompt then states the colour legend and that mannequins, numbers, colours and grid lines must not be drawn.
- Previs renders supply layout only. Never use them as style or identity references.
